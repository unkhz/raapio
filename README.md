## Overview

Raapio (Finnish for "scratch" or "scrape") is a command-line tool designed to analyze and visualize ECMAScript Module (ESM) import graphs in JavaScript and TypeScript projects. It helps you understand the dependency structure of your codebase.

Raapio consists of three main components:

1.  **Analyzer**: Scans your project files to find import and export statements.
2.  **Serializer**: Saves the analyzed graph data, including file timestamps for potential future optimizations (e.g., incremental analysis).
3.  **Visualizer**: Generates an interactive HTML/SVG representation of the dependency graph.

## Features

*   Analyzes `.js`, `.ts`, `.jsx`, and `.tsx` files for ESM `import` and `export ... from` statements.
*   Generates a directed graph representing module dependencies.
*   Saves the graph data to a JSON file (`raapio.graph.json`). This file includes timestamps, which can be used to optimize re-analysis by only checking modified files (conceptual, full incremental update logic not yet implemented).
*   Generates an interactive HTML/SVG visualization of the module graph.
*   Provides a simple Command Line Interface (CLI) for easy operation.
*   Built with [Bun](https://bun.sh/) and TypeScript.

## Usage

You can run Raapio using `bun run src/cli.ts <command>` for development, or `./dist/cli <command>` if you have built the executable.

### `analyze` command

Analyzes the specified directory to build a module dependency graph and saves it to a JSON file.

**Syntax:**

```bash
raapio analyze <directory> [options]
```

**Arguments:**

*   `<directory>`: Path to the project directory to analyze.

**Options:**

*   `--output <filepath>`: Specify the output file for the graph data. Defaults to `raapio.graph.json` in the current working directory.

**Example:**

```bash
bun run src/cli.ts analyze ./my-project --output project.graph.json
# or if built:
# ./dist/cli analyze ./my-project --output project.graph.json
```

### `visualize` command

Generates an HTML visualization from a graph data JSON file.

**Syntax:**

```bash
raapio visualize <graphfile.json> [options]
```

**Arguments:**

*   `<graphfile.json>`: Path to the graph data file generated by the `analyze` command (e.g., `raapio.graph.json`).

**Options:**

*   `--output-dir <dirname>`: Directory to save the HTML visualization files. Defaults to `raapio_visualization`.
*   `--serve`: If present, starts a local HTTP server for the visualization.
*   `--port <number>`: Port for the local server if `--serve` is used. Defaults to `3000`.

**Example:**

```bash
bun run src/cli.ts visualize project.graph.json --serve --port 8080
# or if built:
# ./dist/cli visualize project.graph.json --output-dir my_viz_output --serve 
```

## Graph Data Format (`raapio.graph.json`)

The `raapio.graph.json` file stores the analyzed dependency information. Its main parts are:

*   `version`: The version of Raapio that generated the file (e.g., `"1.0.0"`).
*   `rootDir`: The absolute path to the root directory that was analyzed.
*   `graph`: An object where each key is an absolute module path (string) and its value is an array of absolute paths (strings) of modules it directly imports.
    ```json
    {
      "/abs/path/to/moduleA.ts": ["/abs/path/to/moduleB.ts"],
      "/abs/path/to/moduleB.ts": []
    }
    ```
*   `timestamps`: An object where each key is an absolute module path (string) and its value is the last modification timestamp (number, e.g., from `fs.stat().mtimeMs`) of that file at the time of analysis. This is intended for future optimizations.

## Visualization

The `visualize` command generates a set of HTML, CSS, and JavaScript files. When opened in a browser (or served locally), `index.html` displays an SVG-based graph of your modules.

*   **Layout**: Currently uses a simple circular layout for nodes.
*   **Interactivity**: Nodes display their relative paths or names. Basic hover effects are applied to nodes.
*   **Data**: The visualization fetches its data from a `visualization_data.json` file (which is generated by the `visualize` command) in the same directory.

## Development

To contribute to Raapio or run it in a development environment:

1.  **Clone the repository**:
    ```bash
    # Replace <repository_url_placeholder> with the actual URL
    git clone https://<repository_url_placeholder>
    cd raapio
    ```
2.  **Install dependencies**:
    ```bash
    bun install
    ```
3.  **Run tests**:
    ```bash
    bun test
    ```
4.  **Run the CLI (development mode)**:
    Use `bun run src/cli.ts -- <args>` to pass arguments to the script.
    ```bash
    bun run src/cli.ts -- analyze ./my-sample-project
    bun run src/cli.ts -- visualize my-sample-project.graph.json --serve
    ```
5.  **Build the executable**:
    ```bash
    bun run build
    # The executable will be created in ./dist/cli
    ```
